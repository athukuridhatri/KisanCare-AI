# 🌱 KisanCare AI: Farmer Support Portal

> **Track 4 — AgriN & Regenerative Agricultural Intelligence**

## 🚀 Overview
KisanCare AI is an intelligent, multilingual digital agriculture platform designed to empower smallholder farmers with instant crop disease diagnostics and data-driven soil health analytics. By combining computer vision and machine learning, KisanCare bridges the gap between complex agricultural science and everyday farming practices.

---

## 🛠️ Key Features
1. **🍃 Leaf Disease Diagnostic:** Farmers can upload a photo of an infected leaf. An automated vision model instantly classifies the disease and provides actionable treatment insights.
2. **🌾 Smart Crop Guide:** A machine learning recommendation engine (powered by Scikit-Learn) analyzes soil metrics (Nitrogen, Phosphorus, Potassium, pH) and climate conditions to recommend the optimal crop for maximum yield and soil health.
3. **🌐 Multilingual Accessibility:** Built with Streamlit and translation utilities to ensure regional language support for local farmers.

---

## ⚙️ Tech Stack
* **Frontend/UI:** Streamlit
* **Machine Learning:** Scikit-Learn (Random Forest Classifier)
* **Computer Vision:** Hugging Face Transformers (PlantVillage Dataset / Vision Transformer)
* **Data Processing:** Pandas, NumPy
